# Fire Service Daily

Fire service news, research, LODD reports and publications, gathered automatically every morning.

- **The page:** `docs/index.html`, published with GitHub Pages
- **The news:** `docs/news.json`, rebuilt daily
- **The sources:** `scripts/sources.json` — add or remove sites here
- **The schedule:** `.github/workflows/daily-news.yml` runs about 5 AM Eastern every day

To refresh right away: open the **Actions** tab → **Daily fire news** → **Run workflow**.

Link to one category with `?cat=`, for example `?cat=Local` or `?cat=LODD`.
